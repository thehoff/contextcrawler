# ContextCrawler — proof of claims

Reproducible evidence that the filters cut tokens **and** keep the signal.
Generated by `tests/proof.rs` (`PROOF_WRITE=1 cargo test --test proof`). Do not hand-edit.

**Method.** Each row is a real command's raw output run through the matching
filter via the public `contextcrawler::filter_output` API. Tokens are counted
with the real `cl100k_base` BPE (what a GPT-4/Claude-era model actually pays),
not a character heuristic. **Fidelity** checks that the critical signal (the
failing test, the panic, the error code) survives the filter verbatim.

**Scope.** This is a curated corpus of common dev-command shapes (failures, error lists, a passing run, a busy search), not a random sample — it shows what the named filters do on representative input, not a statistical average over all possible output. Numbers are reproduced exactly by the command above.
