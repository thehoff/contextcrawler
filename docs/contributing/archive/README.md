# Archived contributor docs

These documents are retained for historical reference only. They are not
live contributor guides and may describe paths, names, and processes that
no longer match the current codebase.

They cover two finished pieces of project history:

- **The rtk -> ctxcrl rebrand.** The one-time purge of the upstream
  `rtk`/`contextzip` branding to `contextcrawler`/`ctxcrl`, including the
  text audit and the custom merge driver that was designed to carry the
  rebrand across upstream rebases.
  - `REBRAND_KNOWN_TEXT_AUDIT.md`
  - `REBRAND_MERGE_DRIVER_DESIGN.md`
  - `REBRAND_MERGE_DRIVER_DECISIONS.md`
  - `REBRAND_MERGE_DRIVER_REVIEW_CODEX.md`
  - `REBRAND_MERGE_DRIVER_REVIEW_GEMINI.md`

- **The upstream-merge process.** How the fork tracked and rebased
  against `rtk-ai/rtk`.
  - `UPSTREAM_REBASE.md`

The rebrand is complete. For current contributor guidance see the live
docs one level up (`TECHNICAL.md`, `ARCHITECTURE.md`, `CODING_PRACTICES.md`,
`RELEASING.md`).
