## How to reproduce the dashboard

```bash
# 1. Build (debug or release fine)
cargo build --bin contextcrawler

# 2. Boot against your real DB (this is the production path)
target/debug/contextcrawler gain --web

# OR: boot against the sanitised demo env for screenshots / docs
eval "$(bash scripts/seed-demo-env.sh)"
target/debug/contextcrawler gain --web --port 8773 --no-browser
open http://127.0.0.1:8773/

# 3. To re-screenshot for the README, use playwright through the demo env.
#    See docs/assets/dashboard-*.png for the canonical set.
```

## How to reproduce the perf profile

```bash
cargo build --profile profiling --bin contextcrawler
eval "$(bash scripts/seed-demo-env.sh)"

# Layer breakdown
hyperfine --warmup 5 --runs 20 \
  -n raw                  'git status >/dev/null' \
  -n proxy                "RTK_DB_PATH=\"$DEMO_HOME/Library/Application Support/contextcrawler/history.db\" target/profiling/contextcrawler proxy git status >/dev/null 2>&1" \
  -n full                 "RTK_DB_PATH=\"$DEMO_HOME/Library/Application Support/contextcrawler/history.db\" target/profiling/contextcrawler git status >/dev/null 2>&1"

# Symbolicated samply profile
samply record --rate 10000 --save-only --unstable-presymbolicate \
  --output docs/perf/cc-git-status.profile.json \
  -- target/profiling/contextcrawler git status

# View with full symbols
samply load docs/perf/cc-git-status.profile.json
```
